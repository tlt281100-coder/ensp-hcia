# 中小型企业园区网综合实验（HCIA 方向）

基于华为 eNSP 模拟器完成的一个中小型企业园区网项目，覆盖接入、汇聚、核心三层组网，并接入双运营商互联网出口。本项目用于 HCIA 阶段综合练习与面试项目展示。

![网络拓扑图](docs/images/network-topology.png)

> 图片取自实验记录；详细的分步配置过程见 [docs/项目实现文档.md](docs/项目实现文档.md)。

## 项目目标

1. 园区内网通过 OSPF 单区域互联互通；业务网关位于汇聚层 AGG，服务器网关位于核心 Core1。
2. 核心与汇聚之间使用 LACP 链路聚合，提升带宽并提高可靠性。
3. 使用 VLAN 隔离不同楼层、有线/无线业务，接入层终端通过 DHCP 自动获取地址。
4. AC 集中管理 AP，三个楼层分别提供独立 SSID 与业务 VLAN。
5. 双出口接入互联网：一条电信专线 + 一条 PPPoE 拨号链路，通过两条等价缺省路由实现负载分担，并配置 NAT。
6. 通过 NAT Server 端口映射，使外网客户端可以访问内网 HTTP / FTP 服务器。

## 涉及的技术点

- 网络分层：核心层 / 汇聚层 / 接入层
- VLAN 规划与 Trunk / Access 端口
- Eth-Trunk 手工链路聚合（LACP 模式）
- 三层交换机 VLANIF 网关
- DHCP（接口地址池）+ DNS 下发
- OSPF 单区域路由
- AC + Fit AP（CAPWAP），多 SSID 业务隔离
- PPPoE 客户端拨号 / 服务端认证
- 静态缺省路由与等价路由负载分担
- ACL + NAT（Easy IP）与 NAT Server 端口映射

## 网络规模

主要设备：

| 设备 | 数量 | 角色 |
| --- | --- | --- |
| AR2220 | 1 | 企业出口路由器（双出口） |

| S5700 | 1 | Core1 核心交换机 |
| S5700 | 3 | AGG1-3 楼层汇聚交换机 |
| S5700 | 6 | ACC1-6 楼层接入交换机 |

## 如何使用

1. 安装华为 eNSP 模拟器。
2. 打开本仓库中的 `园区/园区.topo`，启动全部设备。
3. 按 `docs/项目实现文档.md` 中的步骤核对或复现配置。
4. 导出各设备当前配置时，可放入 `configs/` 目录。

## 说明

- 本项目为纯模拟器实验环境，不涉及真实生产配置与真实密码。
- 由于 HCIA 阶段尚未学习业务分流，企业双出口使用等价缺省路由实现负载分担，生产环境中通常结合策略路由或智能选路做业务分流。
- 运营商模拟路由器之间使用 OSPF 互通，仅为实验环境简化。
